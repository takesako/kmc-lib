# kmc-lib

**KMC Library — C Programming Libraries for Beginners**

A collection of simple, beginner-friendly C libraries developed for programming classes at **Kamiyama Marugoto College of Design, Technology, and Entrepreneurship (神山まるごと高専)**.

These libraries are designed to help students learn C programming through hands-on exercises involving graphics, images, sound, and terminal operations.

## Libraries

| File | Description |
|---|---|
| [`kmc_lib.h`](kmc_lib.h) | Terminal input and keyboard utilities |
| [`lib_bmp1.h`](lib_bmp1.h) | Monochrome (1-bit) BMP image generation |
| [`lib_bmp16.h`](lib_bmp16.h) | 16-color BMP image generation |
| [`lib_png16.h`](lib_png16.h) | 16-color PNG image generation |
| [`lib_pav.h`](lib_pav.h) | Palette Animation Video (PAV) encoding and decoding |
| [`lib_macio.h`](https://github.com/takesako/kmc-lib/blob/main/lib_macio.h) | macOS keyboard input and sound synthesis |
| [`mml_lib.h`](mml_lib.h) | Music Macro Language (MML) to WAV audio generation |
| [`fami_mml.h`](fami_mml.h) | Famicom-style sound synthesis and MML to WAV conversion |

## Design Principles

- **Simple:** Keep the implementation short and easy to understand.
- **Beginner-friendly:** Use straightforward C code suitable for programming education.
- **Self-contained:** Provide libraries as header files without complicated dependencies.
- **Hands-on:** Encourage students to learn by creating images, music, and interactive programs.
- **Educational:** Make it easy to read, modify, and experiment with the source code.
